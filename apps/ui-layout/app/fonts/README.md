# Local fonts

These files are the normal-style Poppins weights and variable DM Sans, Manrope and Space Grotesk from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl). Each family retains its original SIL Open Font License alongside the files. They are bundled through `next/font/local` so the Next.js build does not fetch Google Fonts over the network. The original CSS font variables remain unchanged. Preload is disabled to avoid downloading every Poppins weight on initial navigation; the browser requests the styles it uses.
