## Use a real destination

If the action navigates to a sponsorship page, use a link with a descriptive label and the correct destination. Avoid a decorative button that has no payment or support flow attached.

## Customize the artwork

The component documents classes for the container, coffee icon and SVG text. Adjust the treatment to match your visual language without removing the visible support label.

## Explain the outcome

Make clear whether the link opens a third-party service, and keep it keyboard reachable. Do not represent an external payment as completed until that provider confirms it.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```html
<a href='/support'>Support this project</a>
```
