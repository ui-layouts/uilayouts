## Distinguish free drag from sorting

Dragging an item visually does not automatically update a list order. Decide whether the item returns, keeps its position or commits a reordered model.

## Set constraints at the container

Use a reference to a bounding region and test it after resize. Preserve a clear grab handle if the card contains buttons or inputs.

## Handle touch and keyboard

Do not disable scrolling on the entire page just to make a card draggable. Provide keyboard actions for any drag operation that changes saved application state.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```tsx
<motion.div drag dragConstraints={containerRef} dragElastic={0.12}>Drag me</motion.div>
```
