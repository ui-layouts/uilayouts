## Write questions as headings

Use plain user-facing language and avoid hiding the purpose of each item. Answers should be concise and link to detailed documentation when needed.

## Choose the disclosure state

Allow independent opening when users compare answers, or use a single-open state when space is constrained. Animate expansion without clipping long content.

## Preserve keyboard access

Use a real button or details element, expose the open state, and keep closed panel controls out of the tab order. Avoid automatic closing while the reader is interacting with an answer.
