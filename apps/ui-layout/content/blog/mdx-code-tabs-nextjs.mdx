MDX can render interactive code examples alongside prose, which makes it useful for component installation guides.

## Live example from UI Layouts

<CodeTabsMdx>

```bash
npx uilayouts@latest add liquid-gradient
```

```bash
npx shadcn@latest add 'https://www.ui-layouts.com/r/liquid-gradient.json'
```

</CodeTabsMdx>

## Use the actual MDX component

The UI Layouts documentation uses CodeTabsMdx to parse code fence children and highlight them through the site's Shiki helper. It is specialized for one snippet or a pair of installation commands.

## Keep two commands equivalent

The two-tab implementation labels its alternatives UI Layouts and shadcn. Each command should install the same component through a different supported mechanism; do not present arbitrary languages using those labels.

## Map MDX components centrally

Register the wrapper in mdx-components.tsx so authors can write normal code fences. Preserve the original source for copying and handle a single fence without forcing unnecessary tabs.

## Implementation pattern

The rendered pair above is the working authoring example. In your MDX file, wrap the two fenced commands in a CodeTabsMdx element and register it in the MDX component map.
