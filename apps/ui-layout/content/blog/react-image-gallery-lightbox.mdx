## Maintain a stable gallery index

Track the selected photo by ID and derive its position from the current list. If the list changes, close gracefully or select an item that still exists.

## Reserve image dimensions

Use thumbnail dimensions to prevent layout shift and load the larger asset when necessary. Keep the original crop or provide a clearly intentional alternate crop in the overlay.

## Support gallery navigation

Give users previous, next and close buttons, keyboard navigation and descriptive photo alternatives. Return focus to the originating thumbnail when closing.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```tsx
const nextIndex = (index: number, count: number) => count ? (index + 1) % count : 0;
```
