## Separate display from storage

Format for the selected region while keeping a canonical number, typically E.164 after parsing. Do not simply prepend a country code to an arbitrary text string.

## Let users choose the region

Default to a reasonable region only when known and let users change it. A flag alone is not a sufficient accessible name; include the country or region text.

## Validate without blocking typing

A partial number is normal during entry. Validate on blur or submission and distinguish formatting validity from verified ownership; verification needs a separate flow.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```html
<input type='tel' autocomplete='tel' aria-label='Phone number' />
```
