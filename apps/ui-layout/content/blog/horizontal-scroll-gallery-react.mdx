## Choose a native baseline

Use an overflow-x container with scroll snapping for direct horizontal interaction. For vertical-to-horizontal motion, pin a bounded region and map page progress to the required horizontal travel.

## Measure real content width

Calculate the scrollable distance as content width minus viewport width. Recalculate on resize rather than assuming every item occupies the entire viewport.

## Keep navigation accessible

Do not trap keyboard users in a pinned section or hide content beyond a scroll boundary. Provide direct links or controls and disable forced scroll motion when requested.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```css
.gallery { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; }
.gallery > * { flex: 0 0 80%; scroll-snap-align: start; }
```
