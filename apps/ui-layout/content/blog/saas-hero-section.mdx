A SaaS hero should explain what the product does before showing off how it looks. Start with the value proposition and a concrete visual demonstration, then use the AI Value Proposition block to explore composition.

## Write the promise first

Use a headline that names the user outcome and a short supporting sentence that identifies the audience or workflow. Put the primary call to action immediately after the explanation; reserve secondary links for lower-commitment tasks.

## Build a stable visual composition

At desktop widths, use two columns when the product screenshot supports the text. At narrow widths stack the content first and image second. Give the screenshot an explicit aspect ratio and avoid placing essential copy inside the image.

## Connect to the next section

Use features to explain the promise and testimonials or measured results to support it. The hero is not the place to list every integration. Keep animation subordinate to the CTA and preserve the reading order.
