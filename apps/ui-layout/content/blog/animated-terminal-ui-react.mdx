## Model phases as data

Describe each step with a stable ID, label and optional output. Keep the sequence deterministic so it can restart without duplicating earlier lines.

## Separate presentation from execution

The library combines shimmer and typewriter effects. If the terminal is decorative, label it as an example; if it represents real commands, update statuses only from actual execution results.

## Keep the output usable

Use monospace text, allow long output to wrap or scroll, and provide a static transcript for reduced motion. Never animate sensitive credentials or logs in a public demo.
