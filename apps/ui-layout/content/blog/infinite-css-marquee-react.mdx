## Duplicate one full sequence

Render two equal-width repetitions and move the track by exactly one repetition. Include consistent gaps at the seam.

## Choose a speed by distance

A fixed duration produces different speeds for short and long strips. Measure the content width when consistent visual speed matters.

## Provide a static and pause state

Hide duplicate decorative content from assistive technology, pause long-running motion when users request it and keep meaningful links reachable without a moving target.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```css
@keyframes marquee { to { transform: translateX(-50%); } }
.track { display: flex; width: max-content; animation: marquee 20s linear infinite; }
```
