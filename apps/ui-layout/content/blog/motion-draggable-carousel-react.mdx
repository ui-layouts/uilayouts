## Use a stable selected index

Track the active slide in state and use stable IDs for rendered items. Derive the transform from the selected item rather than allowing drag to mutate the index continuously.

## Commit drag deliberately

Decide whether to change slides based on distance or velocity. Clamp the index at the boundaries unless looping is intentionally implemented.

## Avoid gesture conflicts

A horizontal drag should not block vertical page scrolling. Provide conventional next and previous controls, and make autoplay optional and pausable.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```ts
const targetIndex = (index: number, delta: number, count: number) => Math.max(0, Math.min(count - 1, index + delta));
```
