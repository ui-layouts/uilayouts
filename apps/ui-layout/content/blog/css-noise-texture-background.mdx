## Use a dedicated texture layer

Position a small repeating SVG or raster texture over a background. Keep the grain separate from text and controls so the effect does not reduce their clarity.

## Adjust opacity before scale

Start with a low opacity and inspect the result on light and dark surfaces. Fine grain is usually less intrusive than large high-contrast speckles.

## Keep the texture cheap

A static repeated texture is often enough. Avoid animating a full-screen filter continuously unless a measured design benefit justifies the rendering cost.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```css
.grain { position: absolute; inset: 0; pointer-events: none; opacity: .06; background-repeat: repeat; }
```
