## Installation

Use the documented UI Layouts registry command in your React project:

```bash
npx shadcn@latest add 'https://www.ui-layouts.com/r/animated-beam.json'
```

The component documentation includes the full setup and dependency details.

## Measure endpoints in the same space

Use the bounding boxes of nodes relative to the diagram container. Recompute when the layout changes, and avoid hard-coded coordinates for responsive cards.

## Animate along a path

Use an SVG path between node centers, then animate a highlight or dashed stroke along it. Choose direction according to the actual data relationship.

## Do not imply unsupported integrations

Label each node, keep the connection visible without animation, and use accessible text for important relationships. A beam should illustrate a real connection rather than promise one.
