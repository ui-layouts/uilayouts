An image mask controls visibility through alpha or luminance rather than just defining a hard geometric edge.

## Choose mask semantics

A clip path creates a crisp boundary, while a mask can create soft or translucent regions. Use an SVG shape when you want the subject to appear inside a custom illustration.

## Align the mask and image

Set mask-size, position and repeat explicitly, and choose the image's object position separately. Check the artwork at different aspect ratios.

## Provide a useful fallback

If a remote mask fails to load, an image can disappear. Prefer local assets and ensure any information conveyed by the image is also available in text.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```css
.masked { mask-image: url('/shape.svg'); mask-size: contain; mask-position: center; mask-repeat: no-repeat; }
```
