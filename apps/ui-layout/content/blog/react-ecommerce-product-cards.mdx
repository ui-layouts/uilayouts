## Keep commerce data structured

Store product ID, title, image, price, currency and availability in one object. Format prices consistently and avoid displaying a discount without a valid comparison price.

## Reserve image space

Use a shared aspect ratio and meaningful alt text. Keep titles flexible for long product names and avoid cropping details users need to evaluate.

## Separate navigation from purchasing

A product link opens the detail page, while Add to cart is a real button. Do not nest interactive elements inside one another, and communicate stock state explicitly.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```tsx
<article><a href={product.href}>{product.name}</a><p>{formatPrice(product.price)}</p><button type='button' disabled={!product.inStock}>Add to cart</button></article>
```
