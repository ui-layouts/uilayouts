## Use tabs for related views

Each tab should identify a meaningful product feature and have a corresponding panel. The image should illustrate the feature rather than repeat text inside a screenshot.

## Keep the image crop stable

Reserve a common aspect ratio and swap media without shifting the surrounding controls. Preload only the next likely image when it makes sense.

## Preserve tab keyboard behavior

Use a tab primitive with arrow-key navigation and labeled panels. In reduced motion, switch content immediately rather than hiding the new panel behind a transition.
