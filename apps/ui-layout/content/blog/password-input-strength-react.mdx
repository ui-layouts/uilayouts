## Keep visibility under user control

Use password and text input types for the same controlled value. Label the toggle Show password or Hide password and preserve the caret when feasible.

## Treat strength as guidance

Length and common-password screening are more useful than arbitrary composition checkboxes alone. A visual strength meter is not proof that a password is safe.

## Validate at the server

Never log the password or send it to an untrusted scoring endpoint. Support password managers and paste, and use an appropriate password hashing system on the server.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```tsx
<input type={visible ? 'text' : 'password'} autoComplete='new-password' value={password} onChange={e => setPassword(e.target.value)} />
```
