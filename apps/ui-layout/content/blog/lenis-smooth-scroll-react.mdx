## Use a single scroll controller

Avoid running multiple smooth-scroll libraries or independent animation loops on the same page. Coordinate scroll-linked animation with the controller's progress.

## Preserve native browser behavior

Anchor navigation, keyboard scrolling, focus movement and nested scroll areas should continue to work. Do not smooth every wheel event indiscriminately.

## Respect user preferences

Disable optional interpolation for reduced motion and test touch scrolling. Cancel animation-frame work and destroy the controller when it unmounts.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```css
@media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto; } }
```
