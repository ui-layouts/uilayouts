## Make the footer useful first

Keep legal, support and product links in ordinary accessible navigation. The animated logo example is a separate visual layer, not a replacement for those links.

## Reveal near the end

An entrance tied to visibility can avoid spending animation work while the user is reading the top of a long page. Keep the logo's dimensions reserved so the footer does not jump.

## Keep pointer effects optional

Mouse-following effects should not intercept links. On touch devices or reduced-motion settings, show the finished logo without requiring interaction.

## Implementation pattern

The following focused snippet demonstrates the principle, not the complete UI Layouts implementation. The live example and linked documentation contain the full source.

```css
.footer-logo { pointer-events: none; width: 100%; height: auto; }
```
