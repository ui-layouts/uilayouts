A repeating field of images shifts with pointer parallax.

<ComponentCodePreview name='slideshow-infinite-canvas' jsonName='slideshow-infinite-canvas' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-infinite-canvas.json
```

## Usage

```tsx
import { InfiniteCanvas } from '@/components/ui/slideshow-infinite-canvas';

export default function Example() {
  return <InfiniteCanvas images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
