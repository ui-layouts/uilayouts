## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-experimental-carousel.json
```

## Usage

```tsx
import { ExperimentalCarousel } from '@/components/ui/image-effect-experimental-carousel';

export default function Example() {
  return <ExperimentalCarousel images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
