A horizontal strip of framed photographs pans each image as it crosses the viewport.

<ComponentCodePreview name='image-effect-horizontal-parallax' jsonName='image-effect-horizontal-parallax' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-horizontal-parallax.json
```

## Usage

```tsx
import { HorizontalParallax } from '@/components/ui/image-effect-horizontal-parallax';

export default function Example() {
  return <HorizontalParallax images={['/photos/first.jpg', '/photos/second.jpg']} label='Coastal studies' />;
}
```

Scroll or swipe across the gallery. The image moves inside its frame as the frame travels across the screen.

[Original reference](https://github.com/davidfaure/horizontal-parallax-gallery-codrops)
