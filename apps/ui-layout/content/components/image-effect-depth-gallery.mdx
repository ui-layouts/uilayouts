```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-depth-gallery.json
```

## Usage

```tsx
import { DepthGallery } from '@/components/ui/image-effect-depth-gallery';

export default function Example() {
  return <DepthGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the gallery and use the arrow keys for keyboard navigation. Pass labels, swatches and two-color palettes to match each photograph.
