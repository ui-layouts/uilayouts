## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-shader-ripple.json
```

## Usage

```tsx
import { ShaderRipple } from '@/components/ui/image-effect-shader-ripple';

export default function Example() {
  return <ShaderRipple images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Move the pointer over the photograph to activate the effect. The photograph stays in place when the pointer leaves.
