Scrub through the monarch butterfly lifecycle with frame-by-frame sprite animation.

<ComponentCodePreview name='image-effect-sprite-morph' jsonName='image-effect-sprite-morph' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-sprite-morph.json
```

## Usage

```tsx
'use client';

import { SpriteMorph } from '@/components/ui/image-effect-sprite-morph';

import { useState } from 'react';

const base = 'https://www.ui-layouts.com/image-effects/monarch/';
const stages = ['egg', 'larva', 'chrysalis', 'emergence', 'adult'];
const images = stages.map(name => base + name + '.webp');
const atlases = stages.slice(0, -1).map((name, i) => base + name + '-' + stages[i + 1] + '.webp');

export default function MonarchStudy() {
  const [frame, setFrame] = useState(0);
  return (
    <>
      <SpriteMorph images={images} atlases={atlases} labels={stages}
        time={frame / 23} secondsPerImage={1} />
      <input aria-label="Butterfly lifecycle" type="range" min={0} max={92}
        value={frame} onChange={e => setFrame(e.currentTarget.valueAsNumber)} />
    </>
  );
}
```

Drag the slider or use the arrow keys to move one frame at a time. Four transition sheets share their endpoint frames, giving the study 93 distinct positions from egg to adult.

| Prop | Description |
| --- | --- |
| `images` | The images in display order. |
| `labels` | Names used for the captions and selection buttons. |
| `atlases` | Optional transition sheets, one per image-to-next-image pair, including the last-to-first pair only for looping sequences. Each sheet contains 24 frames arranged left to right in six columns and four rows. Without a sheet, the component generates a scanline warp from the two source images. |
| `showCaption` | Show the built-in caption and selection controls. Defaults to true. |
| `time` | Elapsed seconds from an external clock. Supplying this prop selects the frame directly. |
| `secondsPerImage` | Duration of each stage in controlled playback. Defaults to 2.5 seconds. The transition occupies the final second, or the whole stage for durations below one second. |
