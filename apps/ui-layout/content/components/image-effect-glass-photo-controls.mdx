Browse a photo collection with a glass pager that bends the photograph under its edges.

<ComponentCodePreview name='image-effect-glass-photo-controls' jsonName='image-effect-glass-photo-controls' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-glass-photo-controls.json
```

## Usage

```tsx
import { GlassPhotoControls } from '@/components/ui/image-effect-glass-photo-controls';

export default function Example() {
  return <GlassPhotoControls photos={[{ src: '/photos/coast.jpg', alt: 'Pacific coast' }, { src: '/photos/ridge.jpg', alt: 'Mountain ridge' }]} />;
}
```

Use the previous and next buttons to change photographs. WebGPU draws the refractive pager on supported browsers. Canvas 2D renders the refractive effect when WebGPU is unavailable.

[Original reference](https://github.com/jeantimex/glass-effect-webgpu)
