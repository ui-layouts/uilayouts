## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-physics-cloth.json
```

## Usage

```tsx
import { PhysicsCloth } from '@/components/ui/image-effect-physics-cloth';

export default function Example() {
  return <PhysicsCloth images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Click the cloth to change the photograph. The pinned surface responds continuously to wind.
