Each card twists along its vertical axis while crossing the gallery.

<ComponentCodePreview name='slideshow-rotating-gallery' jsonName='slideshow-rotating-gallery' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-rotating-gallery.json
```

## Usage

```tsx
import { RotatingGallery } from '@/components/ui/slideshow-rotating-gallery';

export default function Example() {
  return <RotatingGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
