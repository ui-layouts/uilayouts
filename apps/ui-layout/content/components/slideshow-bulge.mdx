A movable lens pushes the image outward under the pointer.

<ComponentCodePreview name='slideshow-bulge' jsonName='slideshow-bulge' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-bulge.json
```

## Usage

```tsx
import { Bulge } from '@/components/ui/slideshow-bulge';

export default function Example() {
  return <Bulge images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
