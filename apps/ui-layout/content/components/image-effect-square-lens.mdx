## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-square-lens.json
```

## Usage

```tsx
import { SquareLens } from '@/components/ui/image-effect-square-lens';

export default function Example() {
  return <SquareLens images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Move the pointer over the photograph to activate the effect. The photograph stays in place when the pointer leaves.
