## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-scroll-grain.json
```

## Usage

```tsx
import { ScrollGrain } from '@/components/ui/image-effect-scroll-grain';

export default function Example() {
  return <ScrollGrain images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
