A tiled image wall lifts individual panels toward the pointer.

<ComponentCodePreview name='slideshow-interactive-grid' jsonName='slideshow-interactive-grid' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-interactive-grid.json
```

## Usage

```tsx
import { InteractiveGrid } from '@/components/ui/slideshow-interactive-grid';

export default function Example() {
  return <InteractiveGrid images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
