A continuous vertical gallery bends as photographs approach the center.

<ComponentCodePreview name='slideshow-infinite-gallery' jsonName='slideshow-infinite-gallery' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-infinite-gallery.json
```

## Usage

```tsx
import { InfiniteGallery } from '@/components/ui/slideshow-infinite-gallery';

export default function Example() {
  return <InfiniteGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
