## Usage

```tsx
import { Glassformism } from '@/components/ui/glassformism';

export function FrostedCard() {
  return (
    <Glassformism width="280px" borderRadius="24px" blurIntensity="md">
      <div className="relative z-30 p-6">Weather in Berlin</div>
    </Glassformism>
  );
}
```

| Prop | Purpose |
| --- | --- |
| `blurIntensity` | Select the backdrop blur from `sm`, `md`, `lg` or `xl`. Defaults to `xl`. |
| `borderRadius` | Set the corner radius. Defaults to `32px`. |
| `glowIntensity`, `shadowIntensity` | Set the outer glow and inset highlight from `none` through `2xl`. |
| `draggable` | Enable elastic drag. Defaults to `true`. |
| `expandable` | Toggle between the resting and expanded dimensions on click. Defaults to `false`. |
| `width`, `height`, `expandedWidth`, `expandedHeight` | Set CSS dimensions for each state. |
