## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-kinetic-images.json
```

## Usage

```tsx
import { KineticImages } from '@/components/ui/slideshow-kinetic-images';

export default function Example() {
  return <KineticImages images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
