```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-infinite-gallery.json
```

## Usage

```tsx
import { InfiniteGallery } from '@/components/ui/image-effect-infinite-gallery';

export default function Example() {
  return <InfiniteGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
