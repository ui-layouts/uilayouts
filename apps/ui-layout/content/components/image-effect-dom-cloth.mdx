## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-dom-cloth.json
```

## Usage

```tsx
import { DomCloth } from '@/components/ui/image-effect-dom-cloth';

export default function Example() {
  return <DomCloth images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
