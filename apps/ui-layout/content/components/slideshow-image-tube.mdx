Images spiral into a looping three-dimensional tube.

<ComponentCodePreview name='slideshow-image-tube' jsonName='slideshow-image-tube' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-image-tube.json
```

## Usage

```tsx
import { ImageTube } from '@/components/ui/slideshow-image-tube';

export default function Example() {
  return <ImageTube images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
