Liquid Glass bends the content behind its rounded edges. Drag a lens across a logo or photograph to see the edge shift the backdrop.

## Logo lens

<ComponentCodePreview name='liquid-glass-logo-lens' jsonName='liquid-glass' isFitheight />

Drag the lens across the UI Layouts wordmark to see its edges shift beneath the glass. With the lens focused, use the arrow keys to move it and Home to reset it.

## Tide card

<ComponentCodePreview name='liquid-glass-tide-card' jsonName='liquid-glass' isFitheight />

Drag the tide card over the water, then release it to return it to its starting position.

## Landscape icons

<ComponentCodePreview name='liquid-glass-landscape-icons' jsonName='liquid-glass' isFitheight />

Drag either Home icon across the landscape. The clear lens keeps the photograph sharp, while the frosted lens softens the details. Both spring back when released.

## Photo controls

<ComponentCodePreview name='liquid-glass-photo-controls' jsonName='liquid-glass' isFitheight />

Press the glass pager to bend the landscape beneath your pointer. Use the arrows to browse the three photographs.

## Usage

```tsx
'use client';
import { useRef } from 'react';
import { LiquidGlass } from '@/components/ui/liquid-glass';

export function PhotoPager({ src, next }: { src: string; next: () => void }) {
  const photo = useRef<HTMLImageElement>(null);
  return (
    <figure style={{ position: 'relative', width: '100%', aspectRatio: '3 / 2', margin: 0 }}>
      <img ref={photo} src={src} alt="Landscape"
        style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
      <div style={{ position: 'absolute', bottom: '8%', left: '50%', transform: 'translateX(-50%)' }}>
        <LiquidGlass backdropImage={photo} borderRadius="999px" frost={0} bevel={0.22} refraction={1.4}>
          <button onClick={next} style={{ padding: '12px 24px', color: 'white', background: 'transparent' }}>
            Next photo
          </button>
        </LiquidGlass>
      </div>
    </figure>
  );
}
```

| Prop | Purpose |
| --- | --- |
| `borderRadius` | Shape of the glass surface, such as `"50%"` for a circle or `"999px"` for a pill. |
| `refraction` | Strength of the optical displacement, from 0 to 3. Defaults to 1.15. |
| `bevel` | Width of the curved rim relative to the shorter side. Defaults to 0.16. |
| `frost` | Blur radius in CSS pixels. Use zero for clear glass. |
| `backdropImage` | Optional ref to an underlying centered, cover-fit image. This enables a pixel-sampled lens across browsers. The image must be same-origin or permit canvas access. |
| `width`, `height`, `className`, `style` | Size and placement of the surface. |
| `dragWithin` | Pass a ref to the scene to keep the draggable lens inside it. |
| `draggable`, `expandable` | Enable elastic dragging or click-to-expand sizing with `expandedWidth` and `expandedHeight`. |
| `glowIntensity`, `shadowIntensity`, `blurIntensity` | Outer shadow, rim highlights and preset blur levels. An explicit `frost` takes precedence over the blur preset. |

With `backdropImage`, the WebGL shader samples the photograph under the control and bends its colors along the curved rim. Pressing the control distorts the image near the pointer. A Canvas 2D renderer supplies image refraction when WebGL is unavailable. Without an accessible image, the component uses the browser’s backdrop filter.
