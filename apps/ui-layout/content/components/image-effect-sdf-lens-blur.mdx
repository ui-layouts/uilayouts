## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-sdf-lens-blur.json
```

## Usage

```tsx
import { SdfLensBlur } from '@/components/ui/image-effect-sdf-lens-blur';

export default function Example() {
  return <SdfLensBlur variation={0} />;
}
```

Choose any of the four shader variations using the buttons in the preview. Supply an integer between 0 and 3 as `variation`. The shader draws its shapes procedurally.
