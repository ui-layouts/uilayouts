A square lens reveals a second texture with color separation and refraction.

<ComponentCodePreview name='slideshow-square-lens' jsonName='slideshow-square-lens' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-square-lens.json
```

## Usage

```tsx
import { SquareLens } from '@/components/ui/slideshow-square-lens';

export default function Example() {
  return <SquareLens images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
