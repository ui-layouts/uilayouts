## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-bulge.json
```

## Usage

```tsx
import { Bulge } from '@/components/ui/image-effect-bulge';

export default function Example() {
  return <Bulge images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Move the pointer over the photograph to activate the effect. The photograph stays in place when the pointer leaves.
