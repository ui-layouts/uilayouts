An image covers its plane while pointer movement shifts its crop within the remaining margins.

<ComponentCodePreview name='slideshow-object-fit' jsonName='slideshow-object-fit' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-object-fit.json
```

## Usage

```tsx
import { ObjectFit } from '@/components/ui/slideshow-object-fit';

export default function Example() {
  return <ObjectFit images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.

The crop is computed from the image and plane aspect ratios. Pointer coordinates shift the UV origin inside the part of the image that the plane crops away.
[Original reference](https://tympanus.net/codrops/2025/03/11/replicating-css-object-fit-in-webgl/)
