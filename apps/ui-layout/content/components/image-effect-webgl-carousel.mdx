## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-webgl-carousel.json
```

## Usage

```tsx
import { WebGLCarousel } from '@/components/ui/image-effect-webgl-carousel';

export default function Example() {
  return <WebGLCarousel images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll to navigate the stepped strip. Hover to enlarge a card and click it to expand the photograph. Focus the canvas and use the arrow keys for keyboard navigation.
