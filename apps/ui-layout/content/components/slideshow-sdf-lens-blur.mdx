A shaped focus window moves across a softened image.

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-sdf-lens-blur.json
```

## Usage

```tsx
import { SdfLensBlur } from '@/components/ui/slideshow-sdf-lens-blur';

export default function Example() {
  return <SdfLensBlur images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
