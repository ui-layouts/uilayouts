Beveled image tiles wrap around a spherical grid with edge refraction.

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-liquid-glass-grid.json
```

## Usage

```tsx
import { LiquidGlassGrid } from '@/components/ui/slideshow-liquid-glass-grid';

export default function Example() {
  return <LiquidGlassGrid images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.

The cards sit on a staggered spherical surface. A rounded distance field shapes each bevel and offsets the image sampling coordinates across the rim. This WebGL version accepts still images.
[Original reference](https://tympanus.net/codrops/2026/09/08/building-an-infinite-liquid-glass-grid-with-three-js-webgpu-and-tsl/)
