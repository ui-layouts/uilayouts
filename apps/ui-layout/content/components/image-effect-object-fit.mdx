## Usage

```tsx
import { ObjectFit } from '@/components/ui/image-effect-object-fit';

export default function Example() {
  return <ObjectFit images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Choose a frame ratio and move the pointer to shift the crop. The image covers the available area while preserving its original proportions.

The crop is computed from the image and plane aspect ratios. Pointer coordinates shift the UV origin inside the part of the image that the plane crops away.
