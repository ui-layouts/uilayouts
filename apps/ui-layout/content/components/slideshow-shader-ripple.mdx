Concentric waves distort the image and reveal the next texture.

<ComponentCodePreview name='slideshow-shader-ripple' jsonName='slideshow-shader-ripple' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-shader-ripple.json
```

## Usage

```tsx
import { ShaderRipple } from '@/components/ui/slideshow-shader-ripple';

export default function Example() {
  return <ShaderRipple images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
