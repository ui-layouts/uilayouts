A perspective carousel curves adjacent images away from the center.

<ComponentCodePreview name='slideshow-webgl-carousel' jsonName='slideshow-webgl-carousel' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-webgl-carousel.json
```

## Usage

```tsx
import { WebGLCarousel } from '@/components/ui/slideshow-webgl-carousel';

export default function Example() {
  return <WebGLCarousel images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
