Three ways to turn pointer movement into an image trail. Move across a preview, or drag on a touch screen. Images are decorative and do not block links, selection, or page scrolling.

## Smooth Follow

Images ease into place and gently fade away. Use it for portfolios, editorial headers, and image collections.

## Momentum

Images pick up the direction of your gesture, rotate, and drift away. A more expressive option for creative landing pages.

## Pop & Bounce

Each image pops past its natural size, settles, then rebounds before shrinking away. Useful for playful product and campaign pages.

## Usage

```tsx
import ImageMouseTrail from '@/components/ui/mousetrail';

export default function Gallery() {
  return (
    <ImageMouseTrail
      items={['/photos/coast.jpg', '/photos/mountain.jpg', '/photos/forest.jpg']}
      variant="bounce"
      threshold={70}
      maxNumberOfImages={10}
      duration={1500}
    >
      <h2>Good things pop up.</h2>
    </ImageMouseTrail>
  );
}
```

No animation library or extra CSS is required. Each instance owns a bounded image pool and cancels its animations when it unmounts. Failed images are skipped. Fading images finish their exit when the pointer leaves; persistent images clear on leave. Cancelling a touch gesture, resizing, or switching windows clears the trail. Reduced-motion preferences replace movement and scaling with a simple fade.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| items | string[] | Required | Image URLs. An empty list renders the children without a trail. |
| variant | 'follow' / 'momentum' / 'bounce' | 'follow' | Animation style. Momentum and bounce always disappear. |
| children | ReactNode | — | Content displayed above the decorative trail. |
| className | string | — | Container sizing and colors. |
| imgClass | string | 'w-40 h-48' | Image size, crop, border, and shadow classes. |
| threshold | number | — | Distance between images in container CSS pixels. Minimum 8. Overrides distance. |
| distance | number | 20 | Legacy density: container width divided by this value. Higher values emit more images. |
| maxNumberOfImages | number | 5 | Image pool size, clamped to 1–30. Reuses the oldest slot. |
| fadeAnimation | boolean | false | Fade follow images on idle. Otherwise they remain until replaced or the pointer leaves. |
| duration | number | 1200 | Animation lifetime in milliseconds, minimum 400. |
