The trail is a React component written in TypeScript. The examples use Tailwind CSS 4 for styling. Use the `@/` alias for your source directory, or adjust the imports to match your project.

Install the previews and their supporting TypeScript files with shadcn.

```bash
npx shadcn@latest add 'https://www.ui-layouts.com/r/image-mousetrail-explorer.json'
```

The preview defaults to Gooey. Each example’s Code tab shows the variant to use. In a Next.js App Router page, you can import the preview directly.

The previews load the clay WebP files from UI Layouts. To use your own copies, pass the folder URL as `stickerBaseUrl` and place the Shrink Away stickers in its `travel` subfolder.

## Usage

<PreCode typescriptOnly codeblock={{ lang: 'tsx', meta: '', value: `import ImageMouseTrail from '@/components/ui/mousetrail';

export default function Gallery() {
  return (
    <ImageMouseTrail
      items={['/photos/coast.jpg', '/photos/mountain.jpg', '/photos/forest.jpg']}
      fadeAnimation
      threshold={70}
      maxNumberOfImages={10}
      duration={1500}
    >
      <h2>Move to reveal the gallery.</h2>
    </ImageMouseTrail>
  );
}` }} />

No animation library or extra CSS is required. By default, `touchAction="pan-y"` keeps vertical page scrolling available and supports horizontal trail gestures. Set `touchAction="none"` for unrestricted dragging inside the component, as in these previews. Each instance owns a bounded image pool and cancels its animations when it unmounts. Failed images are skipped. Fading images finish their exit when the pointer leaves; persistent images clear on leave. Cancelling a touch gesture, resizing, or switching windows clears the trail. Reduced-motion preferences replace movement and scaling with a simple fade.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| items | string[] | Required | Image URLs. An empty list renders the children without a trail. |
| variant | 'follow' / 'momentum' / 'bounce' | 'follow' | Animation style. Momentum and bounce always disappear. |
| effect | ImageTrailEffect | — | Custom keyframes for advanced trails. Overrides variant and fadeAnimation when set. |
| children | ReactNode | — | Content displayed above the decorative trail. |
| className | string | — | Container sizing and colors. |
| imgClass | string | 'w-40 h-48' | Image size, crop, border, and shadow classes. |
| threshold | number | — | Distance between images in container CSS pixels. Minimum 8. Overrides distance. |
| minInterval | number | 0 | Minimum milliseconds between images. A positive value places one image at the current pointer after both the distance and time thresholds are met. |
| distance | number | 20 | Legacy density: container width divided by this value. Higher values emit more images. |
| maxNumberOfImages | number | 5 | Image pool size, clamped to 1–30. Reuses the oldest slot. |
| fadeAnimation | boolean | false | Fade follow images on idle. Otherwise they remain until replaced or the pointer leaves. |
| duration | number | 1200 | Animation lifetime in milliseconds, minimum 400. |
| touchAction | 'auto' / 'pan-y' / 'none' | 'pan-y' | Touch gesture policy. Use none for two-dimensional dragging. |

## Inspiration

Inspired by the movement and image sequencing in Codrops’ [Image Trail Effects](https://github.com/codrops/ImageTrailEffects) and [Motion Trail Animations](https://github.com/codrops/MotionTrailAnimations). The explorer uses the Web Animations API and Canvas 2D, with its own layouts and Unsplash photo sets.
