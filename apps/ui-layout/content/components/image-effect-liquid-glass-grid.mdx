Beveled image tiles wrap around a spherical grid with edge refraction.

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-liquid-glass-grid.json
```

## Usage

```tsx
import { LiquidGlassGrid } from '@/components/ui/image-effect-liquid-glass-grid';

export default function Example() {
  return <LiquidGlassGrid images={['/photos/meadow.jpg', '/photos/alpine.jpg']}
    videos={['/films/meadow.mp4', null]}
    labels={['Meadow study', 'Alpine ridge']} />;
}
```

Drag in either axis to move across the spherical grid. Tiles flex under drag and settle when released. Add `labels` or muted looping `videos` at matching image indices. The image is the poster while video loads.

The cards sit on a staggered spherical surface. A rounded distance field shapes each bevel and offsets the image sampling coordinates across the rim. This WebGL version accepts still images.
