## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-infinite-canvas.json
```

## Usage

```tsx
import { InfiniteCanvas } from '@/components/ui/image-effect-infinite-canvas';

export default function Example() {
  return <InfiniteCanvas images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag the canvas in either axis, use a trackpad, or focus the canvas and press the arrow keys.
