## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-progressive-blur.json
```

## Usage

```tsx
import { ProgressiveBlur } from '@/components/ui/image-effect-progressive-blur';

export default function Example() {
  return <ProgressiveBlur images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Move the pointer over the photograph to activate the effect. The photograph stays in place when the pointer leaves.
