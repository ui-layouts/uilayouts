Image cards follow a circular arc as they pass across the viewport.

<ComponentCodePreview name='image-effect-circular-gallery' jsonName='image-effect-circular-gallery' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-circular-gallery.json
```

## Usage

```tsx
import { CircularGallery } from '@/components/ui/image-effect-circular-gallery';

export default function Example() {
  return <CircularGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
