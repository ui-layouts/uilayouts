Images move toward the viewer through layers of atmospheric color.

<ComponentCodePreview name='slideshow-depth-gallery' jsonName='slideshow-depth-gallery' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-depth-gallery.json
```

## Usage

```tsx
import { DepthGallery } from '@/components/ui/slideshow-depth-gallery';

export default function Example() {
  return <DepthGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
