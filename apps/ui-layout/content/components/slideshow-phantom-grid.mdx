A floating image grid and a point-cloud face respond to pointer movement.

<ComponentCodePreview name='slideshow-phantom-grid' jsonName='slideshow-phantom-grid' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-phantom-grid.json
```

## Usage

```tsx
import { PhantomGrid } from '@/components/ui/slideshow-phantom-grid';

export default function Example() {
  return <PhantomGrid images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.

Pass an optional `depthMaps` array aligned with `images` to supply depth for each portrait. Dark pixels sit farther from the viewer and light pixels sit closer. The fallback uses a procedural face surface.
[Original reference](https://tympanus.net/codrops/2025/06/30/invisible-forces-the-making-of-phantom-lands-interactive-grid-and-3d-face-particle-system/)
