## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-rotating-gallery.json
```

## Usage

```tsx
import { RotatingGallery } from '@/components/ui/image-effect-rotating-gallery';

export default function Example() {
  return <RotatingGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
