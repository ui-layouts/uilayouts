Delete an item and restore it from the same button. The black pill expands and a checkmark separates from it through an SVG blur and alpha threshold.

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/gooey-delete.json
```

## Usage

```tsx
'use client';

import { useState } from 'react';
import { GooeyDelete } from '@/components/ui/gooey-delete';

export default function Draft() {
  const [deleted, setDeleted] = useState(false);
  return (
    <div>
      {!deleted && <p>Field notes</p>}
      <GooeyDelete itemLabel='Field notes' deleted={deleted} onDeletedChange={setDeleted} />
    </div>
  );
}
```

The `itemLabel` identifies the item to screen readers. Use `deleted` and `onDeletedChange` to connect the button to application state. For a self-managed control, supply `defaultDeleted` instead. Enter and Space activate the focused button. Reduced-motion preferences shorten the transition.
