A floating image bends and separates into color channels as the pointer travels.

<ComponentCodePreview name='slideshow-motion-hover' jsonName='slideshow-motion-hover' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-motion-hover.json
```

## Usage

```tsx
import { MotionHover } from '@/components/ui/slideshow-motion-hover';

export default function Example() {
  return <MotionHover images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
