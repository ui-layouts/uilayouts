## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-gooey-hover.json
```

## Usage

```tsx
import { GooeyHover } from '@/components/ui/image-effect-gooey-hover';

export default function Example() {
  return <GooeyHover images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Move the pointer over the photograph to activate the effect. Click to open the detail state and click again to close it. With the tile focused, Enter or Space also toggles it.
