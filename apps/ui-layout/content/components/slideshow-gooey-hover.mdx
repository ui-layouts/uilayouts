A liquid edge spreads from the pointer to reveal a second photograph.

<ComponentCodePreview name='slideshow-gooey-hover' jsonName='slideshow-gooey-hover' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/slideshow-gooey-hover.json
```

## Usage

```tsx
import { GooeyHover } from '@/components/ui/slideshow-gooey-hover';

export default function Example() {
  return <GooeyHover images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Pass image URLs in display order. Set `time` in seconds to seek to a frame, or omit it for autoplay. Set `pointer={[0.5, 0.5]}` to position the pointer at the center. Your own slider can drive either value.
