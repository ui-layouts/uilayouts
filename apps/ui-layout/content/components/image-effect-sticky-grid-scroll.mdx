```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-sticky-grid-scroll.json
```

## Usage

```tsx
import { StickyGridScroll } from '@/components/ui/image-effect-sticky-grid-scroll';

export default function Example() {
  return <StickyGridScroll images={['/photos/first.jpg', '/photos/second.jpg', '/photos/third.jpg']} title='Field notes' />;
}
```

Scroll inside the component. Supply a title and description to change the text accompanying the expanded image.
