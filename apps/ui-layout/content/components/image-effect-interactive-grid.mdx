## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-interactive-grid.json
```

## Usage

```tsx
import { InteractiveGrid } from '@/components/ui/image-effect-interactive-grid';

export default function Example() {
  return <InteractiveGrid images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Drag the canvas in either axis, use a trackpad, or focus the canvas and press the arrow keys.
