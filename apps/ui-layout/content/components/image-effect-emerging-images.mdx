Horizontal fragments emerge and align into the next image.

<ComponentCodePreview name='image-effect-emerging-images' jsonName='image-effect-emerging-images' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-emerging-images.json
```

## Usage

```tsx
import { EmergingImages } from '@/components/ui/image-effect-emerging-images';

export default function Example() {
  return <EmergingImages images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Move the pointer over the photograph to activate the effect. The photograph stays in place when the pointer leaves.
