The gallery follows a curved path through a sequence of photographs.

<ComponentCodePreview name='image-effect-curve-gallery' jsonName='image-effect-curve-gallery' hasReTrigger isFitheight />

## Installation

```bash
npx shadcn@latest add https://www.ui-layouts.com/r/image-effect-curve-gallery.json
```

## Usage

```tsx
import { CurveGallery } from '@/components/ui/image-effect-curve-gallery';

export default function Example() {
  return <CurveGallery images={['/photos/first.jpg', '/photos/second.jpg']} />;
}
```

Choose one of five paths exported from Blender. Pass `path={3}`, for example, to use the third camera trajectory. Drag or scroll within the gallery to explore. Focus the canvas and use the arrow keys for keyboard navigation.
